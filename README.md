# Kalkulator Konversi Satuan Panjang

Aplikasi desktop berbasis Java untuk melakukan konversi satuan panjang dengan antarmuka grafis (GUI). Project ini dikembangkan sebagai implementasi pembelajaran pemrograman Java, Object-Oriented Programming (OOP), dan pengembangan aplikasi desktop.

## 📌 Tentang Project

**Kalkulator Konversi Satuan Panjang** merupakan aplikasi yang dirancang untuk membantu pengguna mengonversi nilai dari satuan panjang ke satuan lainnya dengan mudah dan cepat.

Aplikasi ini menggunakan JavaFX sebagai teknologi antarmuka grafis dan Maven sebagai build management tool.

## ✨ Fitur

- Konversi antar satuan panjang.
- Antarmuka grafis menggunakan JavaFX.
- Pemisahan kode berdasarkan konsep Model dan Controller.
- Pengelolaan input dan hasil konversi secara interaktif.

## 🛠️ Teknologi yang Digunakan

- **Java** – Bahasa pemrograman utama.
- **JavaFX** – Framework untuk membangun antarmuka grafis.
- **FXML** – Mendefinisikan struktur tampilan aplikasi.
- **Maven** – Dependency management dan project build.
- **Apache NetBeans** – Integrated Development Environment (IDE).

## 🚀 Cara Menjalankan Project

1. Clone repository:

   ```bash
   git clone https://github.com/hizbaiyl/KalkulatorKonversi.git
   ```

2. Buka Apache NetBeans.
3. Pilih **File → Open Project**.
4. Pilih folder `KalkulatorKonversi`.
5. Tunggu Maven menyelesaikan proses dependency resolution.
6. Jalankan project melalui NetBeans.
